Allowance Guard — Guardian Portal

Allowance Guard is a read-only wallet-security agent for BNB Smart Chain (chainId 56). It answers one question for its operator at any time: right now, who can move my tokens, and how much? It audits a wallet's live ERC-20 approvals and reports the standing exposure in plain language.

This portal is the on-chain layer built for the Binance Agent ID Hackathon: after running an audit, a Binance Agent ID holder anchors the audit's summary in the AllowanceGuardRegistry contract on BSC. The contract only accepts calls from addresses that hold an Agent ID, so the registry is a public, verifiable record of Agent ID holders who actively guard their wallets.

Record your security check

  1. Run the audit locally with the CLI below (node index.js <your address> --json) — the scanner is read-only and never signs anything.
  2. Connect the wallet that holds your Agent ID and paste the JSON report. This page hashes the report in your browser; only the hash and the two summary counts go on-chain.
  3. Confirm the recordCheck transaction in your own wallet. Your wallet pays a small BSC gas fee. This contract never asks for any token approval and cannot move your funds.

What the agent does

  1. Scan — walks the wallet's ERC-20 Approval event history on BSC and collects every distinct (token, spender) pair.
  2. Classify — reads the live allowance() for each pair (history alone is not exposure), types each spender (wallet vs contract), flags unlimited or very large allowances.
  3. Report — structured JSON + readable table, with a plain-language verdict per line.
  4. Anchor — an Agent ID holder records the audit summary on-chain in the AllowanceGuardRegistry (this page).
  5. Human approves — the scanner never signs anything. A revocation is prepared as a preview and executed only on the operator's explicit per-action approval, then re-read to confirm the allowance is exactly 0.

Real case study — 2026-11-14

After a Telegram bot session, the agent audited its operator's wallet (0x32E5…76E9) and found three live allowances the bot had obtained, all to unknown spenders: 97.656 USDT and 12.66 USDT plus ≈ 39.9 million units of a game token. After the operator's explicit approval, all three were revoked on-chain and verified back as exactly 0. Total fees ≈ Rp68.
